# JustScreen

Capture, annotate, and edit on your Mac. JustScreen brings screenshots, screen recording, and a video editing studio into one native macOS app.

- Status: in development for macOS 15 and later.
- [Downloads, release notes, and feedback](https://github.com/getjustscreen/releases). No public release is available yet.
